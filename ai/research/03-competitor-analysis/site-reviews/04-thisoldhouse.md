# Competitor Review: This Old House — Types of Insulation (thisoldhouse.com)

**URL reviewed:** thisoldhouse.com/insulation/types-of-insulation (+ insulation-overview,
how-to-choose-the-right-insulation)
**Type:** Media/publisher brand (TV show + content site), ad- and affiliate-supported
**Domain authority:** Very high, strong consumer brand recognition

## Structure
- Comprehensive single-page guide: Intro (expert endorsement/quote) → Common insulation
  materials (4, each with dedicated subsection) → Specialized options (3) → Choosing the
  right insulation (decision criteria/climate) → Proper placement by location (attic, walls,
  basement) → Installation techniques (DIY vs. pro) → Common mistakes to avoid → "Next Up"
  internal links
- Every material presented as a **pros/cons list** (consistently 3 pros / 3 cons) — highly
  scannable
- Diagrams of insulation cross-sections; embedded expert quotes (contractor Tom Silva)
- Related-article and newsletter/membership CTAs throughout

## Strengths
- Best-structured page in the competitive set for a true beginner: pros/cons format is
  extremely scannable, no prior knowledge assumed
- Single page covers nearly the full buyer's journey (types → placement → install method →
  mistakes) — genuinely close to a "start here" hub
- Strong brand trust (recognizable TV/media brand) without feeling like a government spec sheet
- Explains vapor barrier/thermal envelope concepts in plain language, embedded inline rather
  than requiring a separate glossary page

## Weaknesses / gaps
- No real cost/pricing data (typical for media sites monetizing via ads/affiliate, not
  services)
- No R-value chart or climate-zone table integrated into this specific page (lives in other
  articles)
- CTAs are all media-monetization (newsletter, "Join Insider" membership) — no path to
  actually getting matched with an installer
- Some content increasingly behind membership/newsletter gates

## Tone
Approachable, expert-but-friendly — the benchmark tone for this niche. This is the closest
tonal match to what insulationguide.org should sound like.

## Takeaway for insulationguide.org
This Old House is the strongest structural/tonal model to emulate: pros/cons format,
progression from types → placement → install method → mistakes, plain-language technical
terms. Our differentiation: add the cost data TOH omits, integrate the R-value/climate table
directly into the same page instead of scattering it, and replace media-monetization CTAs
with a genuine "Get Matched with a Vetted, Insured Insulation Contractor" pathway.
